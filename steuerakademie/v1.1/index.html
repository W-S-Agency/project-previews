📝 So geben Sie Feedback

  1. Kommentar hinterlassen — Neben jedem Textblock sehen Sie „✏️ Vorschlag". Klicken Sie darauf, schreiben Sie Ihren Kommentar und klicken Sie auf „Speichern".
  2. Mehrere Blöcke kommentieren — Kommentare werden gesammelt gespeichert (in Ihrem Browser).
  3. Feedback absenden — Oben rechts: „📥 Feedback: X Kommentare" → klicken → „Als Datei herunterladen" (.txt) oder „In Zwischenablage kopieren".
  4. An uns senden — Schicken Sie die Datei oder den Text per E-Mail oder WhatsApp.

Hinweis: Gelb markierte Stellen sind offene Punkte, die wir mit Ihnen klären (z. B. Trust-Zahlen, Testimonials, Foto, Rückgabe-Regelung).
