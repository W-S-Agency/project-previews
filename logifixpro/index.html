📝 So geben Sie Feedback

  1. Version oeffnen — Klicken Sie unten auf eine Version und anschliessend auf eine Seite in der Navigation.
  2. Kommentar hinterlassen — Neben jedem Textblock sehen Sie „✏️ Vorschlag". Klicken Sie darauf, schreiben Sie Ihren Kommentar und klicken Sie auf „Speichern".
  3. Mehrere Seiten kommentieren — Kommentare werden seitenuebergreifend gespeichert. Sie koennen beliebig zwischen den Seiten wechseln.
  4. Feedback absenden — Oben rechts: „📥 Feedback: X Kommentare" → klicken → waehlen Sie: „Als Datei herunterladen" (eine .txt-Datei) oder „In Zwischenablage kopieren" (zum Einfuegen in E-Mail oder Messenger).
  5. An uns senden — Schicken Sie die heruntergeladene Datei oder den kopierten Text per E-Mail, WhatsApp oder wie es Ihnen am liebsten ist.

Hinweis: Ihre Kommentare werden lokal in Ihrem Browser gespeichert und bleiben erhalten, auch wenn Sie die Seite schliessen.
