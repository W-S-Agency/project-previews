📝 So geben Sie Feedback

  1. Seite öffnen — oben in der Navigation. Alle Seiten sind erreichbar.
  2. Kommentar hinterlassen — neben jedem Textblock „✏️ Vorschlag" klicken, schreiben, „Speichern".
  3. Mehrere Seiten — Kommentare werden seitenübergreifend gespeichert.
  4. Feedback absenden — oben rechts „📥 Feedback: X Kommentare" → „Als Datei herunterladen" oder „In Zwischenablage kopieren".
  5. An uns senden — Datei oder Text per E-Mail/WhatsApp schicken.

Hinweis: Kommentare werden lokal im Browser gespeichert. Diese Vorschau ist kein Live-Stand — Fotos, Gäste-Zitate und einige Angaben (Lokale, ÖPNV, Öffnungszeiten) sind noch Platzhalter.
