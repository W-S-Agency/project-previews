Hotel AVAlex — Vorschau-Versionen

Inhaltliche Website-Vorschau zum Relaunch von hotelavalex.de (Berlin).

📝 So geben Sie Feedback

  1. Version oeffnen — Klicken Sie unten auf „Oeffnen" und anschliessend auf eine Seite in der Navigation.
  2. Kommentar hinterlassen — Neben jedem Textblock sehen Sie „✏️ Vorschlag". Klicken, Kommentar schreiben, „Speichern".
  3. Mehrere Seiten kommentieren — Kommentare werden seitenuebergreifend gespeichert.
  4. Feedback absenden — Oben rechts „📥 Feedback: X" → „Als Datei herunterladen" oder „In Zwischenablage kopieren".
  5. An uns senden — Datei oder kopierten Text per E-Mail oder WhatsApp an uns.

Hinweis: Ihre Kommentare werden lokal in Ihrem Browser gespeichert und bleiben erhalten, auch wenn Sie die Seite schliessen.
